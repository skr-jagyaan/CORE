# 1. Production Purpose

This document converts **CORE™ ₹39,999 Idea → Market Sprint Architecture v2.0** into a production-ready learner journey.

It specifies:

- the Graphy course structure
- every pre-session learning block
- the learner task before each live session
- the artifact submitted
- what Sudharsan reviews
- the purpose of the personalized session
- the post-session assignment
- the evidence/decision gates
- the final customer deliverables

The product remains:

> **A hybrid learning + application + personalized strategy program.**

The learner does not buy hours of video.

The learner buys:

> **a disciplined way to move one meaningful idea from ambiguity toward a real market decision.**

---

# 2. Production Principle

The experience must follow:

> **LEARN → ATTEMPT → SUBMIT → REVIEW → SESSION → REVISE → EXECUTE → LEARN → DECIDE**

The live sessions are not lectures.

They are reserved for:

> **diagnosis → challenge → judgment → prioritization → interpretation → decision**

# 15. LIVE SESSION 3
# SELECT THE EVIDENCE

## Time

60 minutes recommended

## Session objective

Approve the **evidence-generation method**, not a predetermined test type. A test is only one possible method; research, observation, expert interpretation, commercial action and technical validation may be more appropriate.

## Structure

### 0–15 min — Review

Check problem → decision → uncertainty.

### 15–30 min — Evidence need

Ask:

> What exactly would reduce this uncertainty?

### 30–45 min — Method selection

Examine candidate methods.

### 45–55 min — Design

Specify:

- evidence-generation activity
- procedure
- acceptance criteria
- evidence standard
- decision rule
- stop condition

### 55–60 min — Commit

Confirm execution plan.

## The key intervention

> **Do not tell the learner what method to use.**

Help them determine:

> **what evidence is required, what method can credibly produce it, and what would count as sufficient evidence.**

## Session output

# Approved Evidence Selection Card™
