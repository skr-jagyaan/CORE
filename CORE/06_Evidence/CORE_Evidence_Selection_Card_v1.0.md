# CORE™ Evidence Selection Card™
## Learner Working Tool
### Version 1.0

---

# Purpose

Use this card **after the opportunity has been framed and WWHTBT has been developed**.

Its purpose is to answer one question:

> **What evidence deserves to be generated before we make this decision?**

This is not a test catalogue.

It does not tell you:

> “Run interviews.”

or:

> “Build a prototype.”

It helps you determine:

> **what you need to learn → what evidence would reduce the uncertainty → how that evidence should be generated → what result would change the decision.**

**KNOWN**

Some evidence exists, but it is incomplete.

**ASSUMED**

Believed to be true without adequate evidence.

**UNKNOWN**

There is insufficient evidence to form a meaningful conclusion.

Before approving this evidence-generation activity, verify:

### 1. Problem

☐ The problem frame is clear enough.

### 2. Decision

☐ The decision is explicit.

### 3. Critical uncertainty

☐ The uncertainty could materially change the decision.

### 4. Existing evidence

☐ Existing evidence has been checked first.

### 5. Evidence requirement

☐ We know what evidence is actually needed.

### 6. Method

☐ The selected method follows the evidence requirement.

### 7. Method limitation

☐ We know what the method cannot establish.

### 8. Evidence standard

☐ The evidence standard matches the consequence of the decision.

### 9. Acceptance criteria

☐ Acceptance criteria are defined where applicable.
