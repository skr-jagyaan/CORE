# CORE™ — Current Knowledge & Operating Repository

This repository contains the current CORE™ strategy, commercial architecture, products, evidence systems, community architecture, education/organising architecture, and supporting implementation documents.

## Current architecture

**School of thought:** Building Strategic Systems  
**Thinking framework:** CORE Thinking Framework™  
**Journey:** SIGNAL → IDEA → MARKET → ORGANISATION

### Commercial architecture

- **₹499 — CORE Essentials:** Signal → Idea
- **₹7,999 — Decide With CORE:** owned community / access environment
- **₹39,999 — Idea → Market:** available only to authenticated Decide With CORE members
- **₹5L — Product / Business → Organisation:** independently acquirable by qualified organisations

The ₹7,999 community is an access/environment layer, not a fourth transformation. Decide+ is a capability inside the community.
