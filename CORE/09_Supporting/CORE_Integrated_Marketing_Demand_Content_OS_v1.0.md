# 6. LAYER 2 — SIX MARKETING / VALUE-CONTEXT LEVERS

The six levers answer:

> **How can the same underlying value become more valuable by changing the context in which it is encountered, experienced, accessed and interpreted?**

## PLACE

Where does the customer encounter or buy it?

## MOMENT

When does the value become particularly relevant?

## PACKAGING

How is the value bundled and presented?

## STORY

What meaning surrounds the value?

## ACCESS

How does the customer access the value?

## STATUS

What identity does association with the value reinforce?

### Governing principle

> **The underlying product can remain substantially unchanged while context changes perceived and experienced value.**

These are **market-design levers**, not merely copywriting tricks.

# 12. SEVEN STORYTELLING FRAMEWORKS

Story is a secondary construction layer.

### 1. Hero's Journey
Customer/operator → problem → guidance → transformation.

### 2. Before–After–Bridge
Current state → desired state → bridge.

### 3. Problem–Agitate–Solution
Problem → consequence/tension → relief.

Agitation must create clarity, not manipulation.

### 4. StoryBrand
Customer hero → problem → guide → plan → action → outcome.

### 5. Pixar Pitch
Once upon a time → every day → until one day → because of that → until finally.

### 6. Data Story
Context → surprising finding → meaning → change → action.

### 7. Confession
Misconception/mistake → learning → transformation → invitation.

If a story does not improve understanding:

> **Do not force one.**

# 13. LAYER 5 — BEHAVIORAL / PERCEPTUAL DESIGN

These answer:

> **How does perception influence evaluation and action?**

### Halo Effect
Use relevant proof and demonstrated competence.

### Framing Effect
Change how the strategic problem is interpreted.

### Decoy Effect
Use legitimate comparison/package architecture.

### Loss-Leader Strategy
Use a low-priced entry such as ₹499 as a legitimate gateway to deeper work.

### Anchoring Effect
Establish defensible reference points for value, consequence or standard.

### Scarcity Effect
Use only genuine limits such as session/cohort/advisory capacity.

### Social Proof
Use relevant cases, testimonials, results and peer evidence.

### Rule

> **Behavioral effects are optional optimization layers, never substitutes for a strong intellectual idea.**

# 21. THE SIX SUPPLIED LINKEDIN AUTOMATIONS

The six JSONs become components of one system.

## 1. LinkedIn Post Generation + Gmail Approval

Role:

> **Quality-controlled publishing.**

The supplied workflow uses scheduled execution, Google Sheets inputs, AI generation, Gmail approval/change flow, regeneration, LinkedIn publication and tracking.

Use it as the human-controlled publishing layer.

## 2. Newsletter → LinkedIn Content

Role:

> **External signal → CORE interpretation.**

The supplied workflow extracts news items from newsletter content and generates LinkedIn content.

CORE rule:

> Do not merely summarize news.

Ask:

> **What does this reveal about opportunity, uncertainty, evidence, strategy or decision?**

## 3. LinkedIn Engagement Counter

Role:

> **Content-performance intelligence.**

It aggregates post-level engagement.

Upgrade its question from:

> “Which post got engagement?”

to:

> **“Which CORE ideas attracted relevant ICP attention, and what did those people reveal?”**

## 4. LinkedIn AI Content Automation / Agentic Vibe

Role:

> **Scaled draft production.**

The supplied workflow includes content-topic generation, content creation, image generation, hashtag/SEO generation and LinkedIn publishing.

Its input should become a CORE content-construction brief.

## 5. LinkedIn Commentor Scraper / Apify

Role:

> **Interest-based ICP discovery + language intelligence.**

The supplied workflow captures:

- Profile Name;
- Profile URL;
- Post URL;
- Comment.

Use this to identify people already demonstrating interest in relevant conversations.

Do not mass-message commenters.

## 6. Research Other Creators' Posts

Role:

> **Attention intelligence.**

Use it to understand:

- what ICPs discuss;
- language they use;
- tensions generating discussion;
- useful formats;
- intellectual gaps.

Do not copy creators.

Produce:

> **CORE synthesis.**
