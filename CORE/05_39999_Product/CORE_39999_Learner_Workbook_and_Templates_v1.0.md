# HOW TO USE THIS WORKBOOK

This workbook is the learner's working surface for the CORE™ ₹39,999 Idea → Market Sprint.

It is designed to be used alongside:

- the Graphy lessons;
- the four teaching cases;
- the CORE Evidence-Generation Method Library;
- the personalised sessions.

The learner's **own idea/problem remains the primary case**.

The four teaching cases are used to build judgment.

The workbook follows the product's experience loop:

> **Learn → Apply → Submit → Discuss → Revise → Continue**

The purpose is not to produce perfect documents.

The purpose is to build:

> **better problem framing → better choices → better evidence → better decisions.**
