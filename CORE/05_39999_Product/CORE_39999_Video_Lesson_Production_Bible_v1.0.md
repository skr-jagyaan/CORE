---

# 1. Purpose

This document converts the locked CORE ₹39,999 learner experience and detailed session architecture into a production specification for the actual lessons and videos.

It defines what each lesson must accomplish, how it should open, what it should teach, which case should carry the idea, what the learner should do, what artifact should be created, and how the lesson moves toward the personalised session.

The established product engine requires major lessons to move through:

> **Extract the gold → learner transformation → business situation → narrative → teach → make memorable → apply → artifact → reflection → proof.**

The product standard is:

> **Intellectual surprise → Practical clarity → Application → Real change → Advocacy.**

---

# 2. Production Principle

The course should feel like:

> **a sequence of strategic discoveries**

not:

> a sequence of lectures.

Every lesson should answer:

> **Why should I care?**

then:

> **What is the idea?**

then:

> **What does it change?**

then:

> **What should I do now?**

---

---

# 4. Production Rules

## Rule 1 — One central idea

One lesson should have one primary intellectual job.

## Rule 2 — One memorable distinction

Give the learner one phrase they can retrieve later.

## Rule 3 — One business reality

Anchor abstraction in a decision, problem or situation.

## Rule 4 — One action

The learner should do something after the lesson.

## Rule 5 — Learner as hero

The instructor is the guide; the learner develops capability.

## Rule 6 — No manufactured certainty

Separate:

> evidence / opinion / inference.

## Rule 7 — No artificial hype

Create value through:

- clarity
- usefulness
- application
- support
- evidence
- proof

---

# 5. Production Voice

Use:

- senior
- clear
- specific
- conversational
- intellectually confident
- practical
- challenging without theatricality

Avoid:

- academic lecture tone
- startup-bro clichés
- motivational filler
- framework overload
- unsupported “guaranteed validation” claims
- generic “10X” language

The learner should feel:

> **“Someone experienced is helping me see what I was missing.”**

# REAL-WORLD EVIDENCE ACTIVITY

## Method

Determined individually through the approved Evidence Selection Card.

## Rule

Do not change the method merely because it is inconvenient.

If the method fails to produce useful evidence:

> **record the failure as learning.**

If the critical uncertainty changes:

> return to the evidence-selection logic and revise the method deliberately.

Do not silently substitute a convenient method and treat it as equivalent.

- process diagrams;
- before/after problem frames;

- evidence maps;

# 12. Coach Intervention Rule

When the learner asks:

> **“What should I do?”**

first ask:

> **“What decision are you trying to make?”**

Then:

> **“What would have to be true?”**

Then:

> **“What do you already know?”**

Then:

> **“What evidence would change your mind?”**

Then:

> **“What would you do if the evidence says X?”**

The coach should build decision capability, not dependence.

# 14. Revision Logic

Revision is substantive, not cosmetic.

If Session 3 reveals:

> the critical uncertainty was wrong,

then:

> the WWHTBT and evidence plan may need revision.

If Session 4 reveals:

> the evidence contradicts the problem frame,

then:

> the problem/opportunity frame may reopen.

This is a feature.

> **CORE is a learning system, not a linear form-filling exercise.**

# 18. Beta Strategy

The first beta should be small.

Measure:

### Can learners complete the work?

### Do they understand the distinctions?

### Can they select appropriate evidence without being told the test?

### Does the Evidence Selection Card work?

### Do the personalized sessions materially improve the artifacts?

### Do learners make a clearer/different decision?

### Where do they get confused?

### Where do they skip work?

Revise the product using actual learner behaviour.
