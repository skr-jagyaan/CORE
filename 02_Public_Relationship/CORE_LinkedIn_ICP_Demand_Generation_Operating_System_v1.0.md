> prioritize relationship.

> asks for help / diagnosis / discussion.

> move to direct conversation.

```text

 ↓

 ↓
CONTEXT
 ↓
CONVERSATION
```

> comment → pitch.

Meaningful comment / direct question.

Repeated reactions / saves / shares where observable.

Single meaningful interaction.

Light interaction.

No meaningful signal.

Then:

> **Priority = ICP Fit × Engagement Quality**

Do not let the number replace judgment.
