# CORE Website Architecture
## Version 1.0

### Status

This is an architecture specification, not final website copy.

It is derived from the current CORE Positioning, Transformation, Strategic Narrative, Offer and GTM documents.

The website should organize the CORE intellectual and commercial system without turning the homepage into a product catalogue.

---

# 1. Website Job

The website should perform four functions:

1. **Clarify**
   - What is CORE?
   - Who is it for?
   - What problem does it solve?

2. **Establish authority**
   - books
   - experience
   - cases
   - ideas

3. **Route**
   - help visitors identify their current state
   - direct them to the appropriate next step

4. **Deepen**
   - provide access to the intellectual body of work
   - provide proof
   - provide product / engagement paths

---

# 2. Homepage Job

The homepage should communicate the transformation:

> **SIGNAL → IDEA → MARKET → ORGANISATION**

without requiring the visitor to understand CORE's internal framework vocabulary first.

---

There are more growth possibilities than organisations can safely pursue.

- customers
- technology
- economics
- operations
- buying
- capability
- ecosystem

> **Signal → Idea → Market → Organisation**

₹499

₹39,999

#### PRODUCT → ORGANISATION

₹5L

### Section 5 — How CORE Thinks

> **What Would Have to Be True?**

Clarify the target market.

# 5. Audience Routing

The site should let visitors self-identify.

### “I have noticed something.”

Route:

> Opportunity Signal → ₹499

### “I have an idea.”

Route:

> ₹39,999

### “We have a product/business, but the organisation is the problem.”

Route:

> ₹5L conversation

The website should not present these as a mandatory sequence.

---

# 9. Website Conversion Principle

Do not make every visitor “book a call.”

Use state-based calls to action.

### Signal

> Explore the Opportunity Signal

### Idea

> Explore the 30-Day Sprint

### Mature Organisation

> Start a strategic conversation

---

# 10. Website Boundaries

The site should not:

- make AI the main category
- explain every internal framework
- force a linear product ladder
- make ₹5L appear as “premium coaching”
- overwhelm the visitor with frameworks
- replace the public intellectual library with sales pages

The homepage should make CORE understandable.

Detailed product pages can make the offers concrete.
